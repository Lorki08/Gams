Відкрий і грай

ESP32 піднімає власний HTTP-сервер. Веб-сторінка зберігається у PROGMEM і обслуговується напряму з мікроконтролера — без зовнішнього хостингу.

1
Підключіть ESP32 до вашої WiFi-мережі, вписавши SSID та пароль у код.
2
Після завантаження дисплей покаже IP-адресу (наприклад, 192.168.1.42).
3
Відкрийте цю адресу в браузері телефону або ноутбука та жміть кнопки.
4
Кожне натискання надсилає GET /btn?k=X запит. ESP32 отримує його за <1 мс.

// Викликати кожен кадр — НЕ блокує
void musTick() {
  if (!mus_enabled || mus_notes == nullptr) return;
  unsigned long now = millis();
  if (now < mus_next) return;   // ще не час — вийти одразу

  int freq = mus_notes[mus_idx];
  unsigned long dur = mus_noteDur(mus_durs[mus_idx]);

  if (freq == NOTE_REST) noTone(BUZZ);
  else tone(BUZZ, freq, dur * 85 / 100); // 85% звук, 15% пауза

  mus_next = now + dur;
  if (++mus_idx >= mus_len) mus_idx = 0; // зациклення
}
